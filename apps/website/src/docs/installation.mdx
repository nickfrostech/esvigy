## CLI

Scaffold self-contained illustration components directly into your project's `components/esvigy/` directory with zero extra runtime dependencies.

<PackageManagerTabs cliCommand="add" />

For more details, see the [CLI documentation](/docs/cli).

---

## React

Implementation of the Esvigy illustration library for React and Next.js applications.

<PackageManagerTabs installPackage="@esvigy/react" />

For more details, see the [React documentation](/docs/frameworks/react). Compatible with Next.js App Router and Server Components (RSC).

---

## Vue

Implementation of the Esvigy illustration library for Vue 3 and Nuxt applications.

<PackageManagerTabs installPackage="@esvigy/vue" />

For more details, see the [Vue documentation](/docs/frameworks/vue). Supports Composition API and Single-File Components (`.vue`).

---

## Static SVG

Normalized SVG files for static HTML, Astro, Markdown, and non-framework environments.

<PackageManagerTabs cliCommand="add EmptyBox --framework svg" />

For more details, see the [Static SVG documentation](/docs/frameworks/svg).
