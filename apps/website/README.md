# Esvigy Website & Studio

> Official documentation site and interactive illustration studio for **Esvigy** *(pronounced "es-vee-gee" /ˌɛs.viːˈdʒiː/)*.
>
> 🌐 **Live Website**: [esvigy.vercel.app](https://esvigy.vercel.app)

---

## Features

- 🌟 **Complete Documentation Homepage**: Hero sandbox, "Why Esvigy" features, quickstart installation guide, and live component previews.
- 🎨 **Illustration Studio**: Full illustration catalog with live primary/secondary color pickers, palette presets, and animation toggles.
- 🔍 **Deep Inspection Modal**: 1-click code copying for React and CLI, real-time SVG downloading, and artist attribution.
- 📐 **Responsive Scaling**: Preview cards in multiple sizes (`sm`, `md`, `lg`) and background styles (`dark`, `light`, `grid`).

---

## Live Deployment

The website is continuously deployed on Vercel at **[https://esvigy.vercel.app](https://esvigy.vercel.app)**.

---

## Development

```bash
# Start the Vite development server
pnpm --filter website dev

# Build production bundle
pnpm --filter website build
```
