# Esvigy Website & Studio

> Official documentation site and interactive illustration studio for Esvigy.

---

## Features

- 🌟 **Complete Documentation Homepage**: Hero sandbox, "Why Esvigy" bento grid, quickstart installation guide, and live component previews.
- 🎨 **Illustration Studio**: Full 30-illustration catalog with live primary/secondary color pickers, palette presets, and animation toggles.
- 🔍 **Deep Inspection Modal**: 1-click code copying for React and CLI, real-time SVG downloading, and artist attribution.
- 📐 **Responsive Scaling**: Preview cards in multiple sizes (`sm`, `md`, `lg`) and background styles (`dark`, `light`, `grid`).
