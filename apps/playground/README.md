# Esvigy Playground

> Interactive test environment and showcase for the Esvigy illustration library.

---

## Features

- 🎨 **Live Palette Controls**: Instant primary and secondary color customization with presets.
- ⚡ **Animation Toggle**: Real-time testing of CSS micro-animations.
- 🔍 **Search & Category Filtering**: Filter across all illustrations by category or keyword tags.
- 📐 **Responsive Scaling**: Preview cards in multiple sizes (`sm`, `md`, `lg`) and background modes (dark, light, grid).

---

## Development

```bash
# Start the Vite development server
pnpm --filter playground dev
```
